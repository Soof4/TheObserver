# TheObserver
Un Plugin de Tshock que muestra actividad delictiva o de trampas en el inventario del jugador. (Traducido por [FrankV22](https://github.com/itsFrankV22))

## Permisos
| Permisos           | Descripción                                      |
|--------------------|--------------------------------------------------|
| theobserver.ignore | The observer ignorara a este grupo de jugadores, recomendado para admins. |
| theobserver.rate   | Permite el uso de ``/rate <0-10>`` commando. Se utiliza para hacer al observador más o menos tolerante.. (high -> menos tolerante, lower -> mas tolerante) |
| theobserver.admin  | Permite el uso de ``/factors`` commando. Muestra los factores de jefe para calcular los valores de las ranuras.. |
